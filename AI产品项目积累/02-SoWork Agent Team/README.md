# SoWork Agent Team

我参与了 Agent Team 的协作方案、原型迭代和多模型验证。一期解决用户如何用一句目标发起复杂任务、查看进展并拿到可用结果。二期形成了专属专家团和长期记忆的产品需求。

## 从哪里看起

先看[项目复盘PRD](SoWork%20Agent%20Team_项目复盘PRD.md)第 2.2 节。协作图可以顺着一个任务读下去，看清 Leader 怎样分工、Verifier 怎样验收，以及哪种情况下只需局部返工。想看设计如何经受测试，可以直接读第 4 章的组队触发、产物可用性与并发案例。
