# 语音输入法量化评测

我参与了自研语音输入法的评测设计。精确版考察是否听准、记全，智能版考察整理后的文字是否忠实、能否直接使用。复盘记录了如何在同一批音频上比较自研与四家竞品，以及哪些结果改变了优化重点。

在 1,235 条共同样本上，自研精确版字符错误率为 2.42%。改口是更值得关注的差距。在 23 个改口事件上，自研智能版得分为 33.33%，Typeless 为 42.03%。
