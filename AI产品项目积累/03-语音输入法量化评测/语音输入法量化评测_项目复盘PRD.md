# 语音输入法量化评测｜项目复盘 PRD

*个人事后整理 · 求职作品集版*

**项目概览**　围绕语音输入法优化、迭代的目标，建立精确转写与智能处理双轨评测体系，经过指标规则迭代和统一事实基线重评，完成自研与四款竞品的横向对照。

**关键结果**　在1,235条共同样本上，自研CER为2.42%，智能轨HER为3.35%、KIA为98.74%、幻觉率为1.04%、结构化正确率为99.53%；改口处理和长文本稳定性是后续优先优化方向。

## 一、项目背景与评测目标

### 1.1 项目出发点

项目通过对自研语音输入法与主流竞品的一系列评测，了解各产品的能力现状、相对优势与差距，判断自研的竞争力，并确定后续优先优化的方向。评测既关注底层识别能力，也关注这些能力最终能否转化为好用的产品。

- **精确识别是基础**　先准确、完整、稳定地理解用户说出的内容，听准数字、专名、否定关系和完整句意，为后续智能处理提供可靠输入。
- **智能处理决定最终使用体验**　在识别基础上处理语气词、改口与结构，让最终上屏文本忠实于用户意图、更方便直接使用，体现产品实际“好不好用”。

### 1.2 评测服务的具体目标

- **诊断基础能力**　识别字符错误、长文本漂移和异常截断，区分识别问题与后处理问题。
- **判断智能处理质量**　衡量必要修改量、关键信息保留、改口处理、幻觉与结构选择，避免只看语言是否流畅。
- **定位横向竞争力**　在同一批输入、参考信息与判定规则下对照五个产品，形成优势与差距的依据。
- **支持后续迭代**　将问题落到具体样本和能力切片，建立可持续回归的标准；两轨分别报告，不压缩成一个总分。

## 二、评测对象与样本体系

### 2.1 评测对象

本次评测覆盖自研语音输入法的两个版本及四家竞品，比较基础转写准确性与智能文本处理能力。

- **自研精确版**　评估基础语音识别与转写能力。
- **自研智能版**　评估智能处理后的文本质量与可用性。
- **Typeless**　Typeless 语音输入法。
- **Wispr Flow**　Wispr Flow 语音输入法。
- **智谱**　GLM-ASR-2512 语音识别模型。
- **豆包**　豆包语音识别模型。

### 2.2 共同样本、标签与适用分母

原始数据集共1,243条，剔除8条执行损耗样本后，形成1,235条共同子集。损耗包含Typeless调用失败5条、空结果3条，属于采集可用性问题。正式横向结果统一引用共同子集。

共同子集包含中文1,144条、粤语63条、混合语言22条、英语6条。混合语言沿用数据集mixed标签，不仅限于中英混说。样本标签用于控制覆盖和定位问题，本身不计分：

- **使用场景**　即时通讯、内容创作、办公事务、搜索查询、生活服务、信息填写、垂直领域等。
- **内容特征**　多语言混说、关键信息、长文本，允许一条样本同时具有多个特征。
- **声学特征**　口音、语速和环境噪声，帮助区分输入条件带来的影响。
- **智能专项**　是否存在改口，以及必须结构化、可选结构化、无需结构化三类需求。

共同子集不等于每项指标都除以1,235。语义有效样本通常为1,158条，KIA对应2,947个事实点，SR对应23个改口事件，结构化对应856条适用样本；智谱分别为1,157条、2,945个事实点和855条结构样本。字符类、语义单元类指标还需使用各自的实际统计量。长文本指标仅在适用长文本中计算，本文沿用报告汇总结果。

## 三、双轨指标与自动评测方案

### 3.1 精确版与智能版分别评什么

| 适用版本 | 指标 | 衡量内容与方向 |
| --- | --- | --- |
| 精确版 | 字符错误率CER ↓ | 字符替换、删除与插入的总体负担，判断转写准确性。 |
| 精确版·长文本 | CER漂移、异常截断率 ↓ | 长音频不同片段的识别波动，以及是否提前停止。 |
| 智能版 | 需人工编辑率HER ↓ | 使输出忠实且可用所需的必要字符修改比例。 |
| 智能版 | 关键信息准确率KIA ↑ | 数字、日期、金额、专名等最终有效事实是否正确保留。 |
| 智能版·改口事件 | 自我修正SR ↑ | 能否同时删除旧内容并保留最终表达。 |
| 智能版 | 幻觉率Hall ↓ | 输出语义中无依据或与最终意图矛盾的内容占比。 |
| 智能版·结构专项 | 结构化正确率Struct ↑ | 结构选择与内容关系是否正确，而非列表生成得越多越好。 |
| 精确版、智能版分别统计 | 首字时延FTL、整句时延UTL ↓ | 从开始送入音频到首字稳定显示、最终文本稳定完成的耗时。 |

CER按参考字符汇总；HER按必要编辑字符汇总；Hall按输出语义单元汇总；SR先计算每个改口事件，再对事件取平均，不能相互替代。 [查看附录中的指标计算公式](#metric-formulas)。

### 3.2 程序、模型与人工的分工

自动评测方案将可确定计算与语义判断分开，避免让评审模型直接估算百分比。

| 评测流程 |
| :---: |
| **① 固定音频、参考文本与标签；冻结规则和评审配置** |
| ↓ |
| **② 采集各产品输出、时间戳及异常记录** |
| ↓ |
| **③ 程序计算确定性指标，模型提交结构化语义判定** |
| ↓ |
| **④ 检查字段、证据与分母，人工抽检标签和评审结果** |
| ↓ |
| **⑤ 汇总总体与主要切片，输出报告并进入回归** |

- **程序**　负责文本归一化、字符距离、时延统计、分母校验和结果聚合，确保同一规则可以重复执行。
- **评审模型**　依据参考信息提出必要修改、匹配事实、判断原子语义与结构关系，提交证据和结构化字段。方案要求隐藏产品身份并固定模型、提示词与输出格式。
- **人工抽检**　方案将人工定位为抽检与纠偏，重点检查标签边界、参考证据和评审误判；抽检不达标时修订规则并统一重评。

### 3.3 内容改写与保真规则

允许删除无意义语气词、合理断句、等价数字表达和不改变原意的同义改写；不允许遗漏限制条件、改错关键事实，或补出用户没有表达的信息。涉及改口时，以最终有效表达为准，同时保留原始参考中的改口过程，供规则核验。

### 3.4 结构化需求打标与判定规则

评测前，根据用户对表达形式的要求，为样本标注结构化需求；评测时，再依据对应标签判断输出的组织形式和内容关系是否正确。

- **必须结构化**　用户明确要求列清单、分几点、按步骤或做表格，应检查是否按要求组织，且条目和层级关系正确。
- **可选结构化**　包含多个事项但未明确指定形式，合理段落与合理列表均可，不因没有生成列表而扣分。
- **无需结构化**　短消息、搜索词、表单值、单项指令或自然叙述可直接使用时，不应因形式加工破坏原意和可用性。

难以明确分类时，按可选结构化处理。

## 四、关键评测问题与规则迭代

指标优化的重点，是让分数更准确地表达错误程度与用户损失。以下短例用于说明计算规则。

### 4.1 HER：从“这句要不要改”转向“必须改多少”

早期HER将每条输出判为需要修改或可以原样使用。这样一处错字与整段严重错误同样计一次，无法反映编辑负担，也容易把可选润色混入评分。

二轮改为生成最小必要后编辑文本PE，再由程序计算输出与PE的字符级最小编辑距离，按字符规模汇总。PE只修复影响忠实性、正确性和直接使用的问题，不做额外润色。示意：“今天天气真号。”改为“今天天气真好。”，7个字符中必要替换1个，HER为14.29%。因此，最终HER为3.35%代表必要字符修改比例，不能转述为96.65%的句子无需修改。

### 4.2 Hall：从句级二元判断转向原子语义统计

早期只判断一句话是否包含幻觉，且将已有字段改错、旧表达残留排除在幻觉外。句级判断难以区分少量无依据补充与大量编造，也无法统一覆盖与用户最终意图矛盾的内容。

二轮将输出拆成可独立核验的原子语义单元，逐个判断有依据或无依据，再按全部输出单元汇总。每个单元最多计一次，遗漏由HER、KIA等指标补充衡量。示意：输出包含“明天下午开会”和“会议地点在A楼”两个单元，前者有依据、后者无依据，Hall为50%。语言流畅不能抵消无依据的信息。

### 4.3 SR：从整句全对转向改口事件的双向检查

早期要求最终表达正确且旧内容完全消失，否则整句记零，难以区分“旧内容仍残留”与“新内容丢失”。二轮先从参考文本确定改口事件，冻结应删除的旧单元与应保留的最终单元，再分别检查旧内容移除率ORR与最终表达保留率FER，以两者调和平均得到事件得分，最后按事件平均。

示意：用户从“你拿13个”改口为“你拿15个”时，需要同时删去被推翻的13个、保留最终的15个。只删掉旧表达却遗漏新表达，或新旧表达都留下，都不能算完整处理。这一规则同时约束“删得干净”和“留得完整”。

### 4.4 统一事实基线与参考答案，重评已有输出

仅统一公式仍不足以保证可比：不同评审若提取出不同事实点、改口事件或无效样本，分数仍会变化。本轮在同一参考文本和冻结标签基础上，共用语义事实基线，由同一评审者按统一规则重评五个产品，程序再汇总并核对适用分母。

重评复用了已有识别输出，没有重新识别音频。它解决的是评分基准和判定口径的一致性，因此跨轮分数变化不能直接归因于模型进步。本轮共同子集内仍保留智谱一条输出归一化为空所造成的分母差异，按报告实际分母披露，不用统一样本总数掩盖该差异。

### 5.3 优势、竞品特点与主要差距

- **自研优势集中在保真与编辑负担**　HER、KIA、Hall与Struct四项结果最优，说明在本轮样本和规则下，必要修改较少、关键事实保留较好，无依据补充较少。结构化99.53%说明结构选择及关系正确，不能解释为主动生成列表的比例。
- **改口处理存在明确差距**　Typeless的SR为42.03%，高于自研33.33%；自研高于Wispr Flow的21.74%。本项按23个改口事件的得分汇总，说明自研已有一定处理能力，仍需加强对最终意图和连续改口的理解。
- **竞品呈现不同取向**　豆包在竞品中HER最低、KIA最高，编辑负担相对较低；Typeless改口处理数值较高；Wispr Flow幻觉率接近自研，但关键事实保留仍有差距。智谱与豆包SR为0，表示适用事件未满足最终意图处理标准，不代表整体识别准确率为0。

## 六、项目成果与后续优化重点

### 6.1 已形成的项目成果

- **建立可解释的双轨体系**　将基础识别与智能处理拆开，用标签和专项指标定位问题，避免字符差异掩盖语义质量。
- **完成关键规则迭代**　HER从句级二元转为必要字符修改量，Hall转为原子语义统计，SR转为改口事件双向检查，明确合理改写和结构需求边界。
- **完成五产品对照**　在共同样本与事实基线下复用已有输出、统一重评，形成可追溯的结果与竞争力判断。
- **明确优化优先级**　保留自研在准确性和保真上的优势，将改口处理、长文本稳定性与持续回归作为下一步重点。

### 6.2 后续优化重点

第一，优先提升改口处理。围绕旧内容残留、改口标记清理、最终信息丢失和连续改口形成专项回归集，同时观察ORR与FER，避免通过过度删除换取单项得分。现有23个事件可作为起点，需补充更丰富的表达与声学条件。

第二，专项治理长文本稳定性。沿时间片定位错误集中区，区分识别漂移、停顿分段和异常截断；在相同长音频上复测，分别追踪漂移与截断，不能用总体CER较低替代专项验收。

第三，建立持续回归。固定数据、参考答案、标签和规则版本，新增问题先核验参考信息，再进入回归集；质量提升同时守住KIA、Hall和响应P95，并在更一致的链路条件下复测时延。

## 附录　指标计算公式

以下公式节选自本人随复盘整理的《指标计算公式》。比率以百分数展示。

| 指标 | 计算方式 |
| --- | --- |
| 字符错误率 CER | （替换字符数 + 删除字符数 + 插入字符数）÷ 参考文本字符总数。 |
| 长文本 CER 漂移 | 对每条长音频计算最高片段 CER 与最低片段 CER 的差，再对适用长音频取平均，以百分点表示。 |
| 长文本异常截断率 | 提前停止识别的长音频数 ÷ 适用长音频数。 |
| 需人工编辑率 HER | 对每条输出计算到最小必要修改稿的编辑距离。汇总编辑距离，除以各样本中输出与修改稿两者较长字符数之和。 |
| 关键信息准确率 KIA | 正确保留的最终有效事实点数 ÷ 参考文本中最终有效事实点总数。 |
| 改口处理得分 SR | 对每个改口事件，分别计算旧内容移除率和最终表达保留率。取两者的调和平均，再对所有有效事件取平均。两项均为零时，该事件记零。 |
| 幻觉率 Hall | 缺乏依据或与最终意图矛盾的输出语义单元数 ÷ 全部输出语义单元数。 |
| 结构化正确率 Struct | 组织形式和内容关系均正确的样本数 ÷ 适用样本数。 |
| 首字时延 FTL、整句时延 UTL | 从开始送入音频计时，分别量到首字稳定显示、最终文本稳定完成。P95 为有效记录的第 95 百分位数。 |
